    关于 JevLand

    JevLand 是什么

    JevLand 是 TypeSafe 公司 Jev 判断模型的非官方中文社区。Jev 不生成文字，只做判断：给它 state（上下文）和一道题（Choice 选择题 / Score 打分题 / Noul 是非题 / Box 框选题），返回带概率和置信度的结构化答案。

    这里提供中文文档、实战教程和更新速递，方便中文用户上手 System One。

    非官方声明

    JevLand 是非官方社区，与 TypeSafe 无隶属关系。Jev、TypeSafe 是其各自所有者的商标。产品功能、定价、SLA 与账号事宜，一律以 TypeSafe 官方说明为准。

    翻译说明

    文档翻译自 TypeSafe 官方英文文档，内容以英文原文为准。每篇文档顶部会标明原文链接和同步日期。发现错译、漏译或链接失效，请在 X 上 @jev_chat 留言，或在公众号「杰哥的AI踩坑日记」留言。
