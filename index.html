    Primitives

    四种题型，一个接口

    Choice

    从一组固定选项里选出一个，返回每个选项的概率和置信度。

    choice · probabilities · confidence

    Score

    按你给的量表打分，返回加权分数、各档概率和置信度。

    score · probabilities · confidence

    Noul

    判断一个命题是真是假，返回 0–1 的概率和置信度。

    noul · confidence

    Box

    1.14 新增

    从选项里勾选多个，返回选中集合、各选项概率和置信度。

    selected[] · probabilities · confidence

    入门

    • 简介

      Jev 是 TypeSafe 的旗舰判断模型，也是首个 System One 模型。传入 state 和类型化问题，直接返回代码可用的结构化答案，不生成文字。

    • 快速开始

      用 Jev 跑通第一个判断请求：申请 API key，选 SDK、HTTP API、agent skill 或 Playground 四条路之一，五分钟内看到带概率和置信度的答案。

    • Jev 与编程智能体

      在编程智能体里，Jev 负责结构化判断而不是写代码。本页说明 Jev 适合做什么、不适合做什么，以及怎样接到 agent 工作流。

    • 用例地图

      按行业看 Jev 能接进哪些软件工作流：客服分流、审核、检索重排、抽取与对齐。把有潜力的判断想法落到可执行的代码路径里。

    核心概念

    • System One

      System One 是为软件做快速、结构化判断的模型系列。Jev 是 TypeSafe 的旗舰 System One 模型，给 state 出题，返回带类型的答案。

    • State（上下文状态）

      Jev 的 state 是判断所依据的上下文：字符串、对象或图片。本页说明如何组织 state，以及怎样给 System One 提供足够信息。

    • 怎样用 TypeSafe 构建

      怎样用 Jev 构建 AI 软件：让代码掌握控制权，把窄而结构化的判断交给 System One，避免把生成式模型硬拧成决策引擎。

    • AI 入门

      介绍 TypeSafe 为何训练 Jev 这类决策模型时使用校准过的概率，而不是针对生成文本做优化，方便代码直接消费判断结果。

    题型

    • 题型总览

      Jev 四种题型总览：Choice 选择题、Score 打分题、Noul 是非题、Box 框选题。说明返回值形态、如何选题，以及一次请求提多个问题。

    • Choice（选择题）

      Jev 的 Choice 选择题从固定选项里选出一个，返回所选选项、每个选项的概率和置信度，适合意图分类、动作选择等路由场景。

    • Score（打分题）

      Jev 的 Score 打分题按你给的有序档位评分，返回加权分数、各档概率和置信度，适合风险、紧急程度、质量这类量表判断。

    • Noul（是非题）

      Jev 的 Noul 是非题判断一个命题是否成立，返回答案为「是」的概率。适合催促、投诉、是否需要人工这类二元门槛判断。

    设计模式

    • 设计模式

      用 Jev 构建系统的架构设计模式：意图路由、置信度分流、组合打分、扇出与护栏。把题型组合成可维护的判断流水线，而不是堆提示词。

    • 推测式扇出

      Jev 的推测式扇出：一次调用发出多个问题，包括暂时不一定相关的题，再由代码根据答案决定哪些真正用得上，避免来回补问浪费。

    • 置信度分流

      把 Jev 置信度当作第二条判断轴：答案告诉你是什么，置信度告诉你能不能自动执行。高置信走代码，低置信交给人或大模型复核。

    • 组合打分

      把复杂判断拆成若干 Jev 子项打分，再用代码里指定的权重合成总分。适合多因素风险、质量评估和需要可解释权重的场景接入。
