    jev-bisect

    作者 mkly 2026-10-05 开源项目 开源PythonSDK
    其他

    Jev 在里面判断什么

    每轮用 Choice 判断当前猜测是 higher、lower 还是 exactly

    它是什么

    jev-bisect 用 TypeSafe 官方 Python SDK，在给定上下界里对一个数字问题做二分搜索。Jev 选出 exactly 之后才返回结果。

    仓库 2026-10-05 创建，Show HN 在 2026-10-08。可配置精度和最大轮数；每轮记录 state、选项、置信度、概率和模型版本。

    Jev 在里面做什么判断

    每一轮把当前猜测交给 Jev，用 Choice（选择题）在 higher、lower、exactly 里选一个。库根据选择收缩区间，直到 exactly 或达到 max_turns。

    怎么试

    pip install jev-bisect，设置 TYPESAFE_API_KEY。仓库：mkly/jev-bisect。
