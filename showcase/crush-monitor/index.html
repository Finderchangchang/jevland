    Crush Monitor

    作者 FerryCorleone 2026-09-20 产品 产品微信聊天中文
    聊天副驾

    Jev 在里面判断什么

    对聊天记录做情绪、意图和回复质量等结构化判断

    它是什么

    Crush Monitor 是一个本机部署的微信聊天分析小工具：导入聊天记录后看情绪曲线、好感信号和自己的回复评分。数据留在本机，密钥在网页里填。

    仓库 2026-09-20 创建。默认推荐 TypeSafe Jev；也可以走 OpenAI Decisions 或普通文本模型，作者写明不同模型结果会有差别。

    Jev 在里面做什么判断

    README 把 Jev 用在分类、打分和概率上，覆盖情绪、意图和好感相关信号。原作者没有在首页列出每道题的题型字段；从描述看是 Choice 与 Score 的组合。
