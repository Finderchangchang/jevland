    jev-cli

    作者 joshLong145 2026-09-21 开源项目 开源CLI日志运维
    数据抽取校验

    Jev 在里面判断什么

    对日志窗口并行 Noul、Score 和 Choice：是否事故、严重度、类别

    它是什么

    jev-cli（命令 jcli）读取 JSON、NDJSON、JSONC 系统产物，按窗口调用 Jev，把类型化答案标回原先行号。Show HN 标题是 CLI wrapper for JEV。

    Show HN 日期 2026-09-21。README 示例用 logs.triage 包，一次给出 is_incident、severity、category。

    Jev 在里面做什么判断

    示例里三道题并行：Noul 问是不是事故，Score 问严重度档位，Choice 问类别（如 application / dependency）。带置信度，可用 --mark-uncertain 标低把握结果。

    怎么试

    仓库：joshLong145/jev-cli。./scripts/install.sh 后设置 TYPESAFE_API_KEY。Show HN：2026-09-21。
