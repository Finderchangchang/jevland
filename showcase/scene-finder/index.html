    它是什么

    Scene Finder 是 Emmy（@techemmyleke）在 2026-10-17 发的开源演示：你描述想找的电影镜头，Jev 在片子里对时间点。帖文写支持 Windows 和 Apple silicon，需要自己的 Jev API 密钥。作者回复里说，找到之后可以剪成梗图。

    公开材料是这条带视频的帖子。检索 GitHub 用户名和「scene finder jev」没有找到对应仓库。

    Jev 在里面做什么判断

    帖文只写用 Jev 按描述找镜头。原作者没有公开具体题型。从「描述场景、在片子里定位」可以看成对片段做是否匹配的判断，字段名没有写出来。
