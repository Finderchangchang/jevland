    MySQL AILIKE

    作者 maayanlevy 2026-09-20 开源项目 开源数据库MySQLSQL

    Jev 在里面判断什么

    把每行文本做成是非判断：是否满足自然语言条件

    它是什么

    AILIKE 是一个 MySQL 原生插件，让 SQL 按「意思」过滤行或比较两列。预览版，需要 TypeSafe API 密钥；被评估的值和提示会发到 TypeSafe。

    仓库 2026-09-19 创建，Hacker News 条目在 2026-09-20。语法包括 column AILIKE 'condition' 和三参数 ailike(left, right, prompt)。

    Jev 在里面做什么判断

    每条未缓存的求值会问 Jev：这个值是否满足条件，或左右两列是否描述同一类产品。匹配返回 1，否则 0。原 README 把问题写成是非形式，对应 Noul（是非题）。

    怎么试

    仓库：maayanlevy/mysql-ailike。文档里有安装说明和 Docker 演示数据集。
