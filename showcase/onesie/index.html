    onesie

    作者 frodi-karlsson 2026-09-28 开源项目 开源CLI管道
    智能体护栏

    Jev 在里面判断什么

    对 stdin 或 --state 提问，用概率和退出码做门禁

    它是什么

    onesie 是一个可进管道的命令行：喂一段文本、问一个问题，拿到能写进脚本的数字或退出码。也可以当 Claude Code 插件。

    Show HN 日期 2026-09-28。除 TypeSafe Jev 外，还可以走 OpenRouter、Berget 的 System One 或 Levanto Sage。带 onesie calibrate，用已标注样本看阈值。

    Jev 在里面做什么判断

    可以把「这段是否紧急」做成是非概率，或用内置 shell-safety 判断一条命令该跑、该拦还是该问人。退出码区分这三种结果。默认后端是 Jev。

    怎么试

    brew install frodi-karlsson/tap/onesie 或 go install github.com/frodi-karlsson/onesie/cmd/onesie@latest，再 onesie auth set。仓库：frodi-karlsson/onesie。
