    TypeSafe Mario

    作者 fhshaik 2026-09-16 演示 演示游戏开源

    Jev 在里面判断什么

    用 Choice 从合法手柄动作里选下一步

    它是什么

    TypeSafe Mario 是一个实验控制器：把 NES 模拟器的遥测和 RAM 收成面向对象的 JSON，交给 Jev 选手柄输入，再推进若干帧。仓库不含任天堂 ROM。

    仓库 2026-09-16 创建。输入包括马里奥运动、跳跃轨迹、前方敌人、地形、响应延迟和关卡进度，不把原始截图发给模型。

    Jev 在里面做什么判断

    Jev 用 Choice（选择题）从一组合法动作里选一个：noop、right、right_jump、right_run、right_run_jump、jump、left。本地代码执行该动作并推进模拟器。

    怎么试

    仓库：fhshaik/typesafe-mario。需要 Python 3.13、TYPESAFE_API_KEY，以及你合法持有的游戏文件。可用 typesafe-mario state-demo 先看将要发给 TypeSafe 的 JSON。
