    Jev 街牌闯美

    作者 henry 2026-10-15 演示 演示导航视觉
    游戏与机器人决策

    Jev 在里面判断什么

    每个路口根据街牌和目的地选择行驶方向

    它是什么

    henry（@arithmoquine）在 2026-10-15 发视频：Jev 按 Cannonball Run 从纽约开到洛杉矶，每个转弯只根据目的地地址和当前街道名选方向。TypeSafe 官方账号转发了这条。

    公开材料是这段视频帖，没有找到单独的代码仓库。

    Jev 在里面做什么判断

    每个路口做一次方向选择。原帖写成 picking a direction at every turn，对应 Choice。街牌输入与 1.14 看图能力同一周出现，帖文没有写模型版本号。

    怎么试
