    jegrep

    作者 can1357 2026-09-19 开源项目 开源搜索代码CLI
    检索结果过滤

    Jev 在里面判断什么

    对目录、文件和代码片段做 Noul 相关性判断，返回行号范围

    它是什么

    jegrep 是一个面向源码树的语义搜索工具，用法接近 grep：描述你要找的东西，它在当前目录上现场搜，不建向量索引、不跑后台守护进程。

    仓库 2026-09-19 创建。结果带原始行号，格式类似 dirname/filename:first-last，可直接贴进编辑器。也提供 --json 给脚本和编程智能体用。

    Jev 在里面做什么判断

    Jev 给候选目录、文件和有限代码片段打绝对的是非概率。本地策略负责预算、阈值和回退。README 写的是校准过的 yes/no 概率，对应 Noul（是非题）。

    怎么试

    cargo install jegrep，或从 GitHub Releases 下载。需要 TypeSafe API 密钥。仓库：can1357/jegrep。
