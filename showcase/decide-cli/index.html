    decide

    作者 vsekhar 2026-09-20 开源项目 开源CLI脚本
    智能体护栏

    Jev 在里面判断什么

    把命令行问题映射成 Noul、Choice 或 Score

    它是什么

    decide 让你在终端、管道和智能体技能里调用决策模型，不必写代码。可以返回答案、置信度、概率，或整份选项分布。

    仓库 2026-09-20 创建，Show HN 在 2026-09-28。可用 Homebrew 安装，配置项是 --model typesafe:jev-latest 和 API 密钥。

    Jev 在里面做什么判断

    默认是是非题（Noul）。--option 变成 Choice（选择题）。也可以提供 --context 把工单等文件当作 state。输出设计成可被脚本读取。

    怎么试

    brew install vsekhar/tap/decide，然后 decide --set-config --model typesafe:jev-latest --api-key -。仓库：vsekhar/decide。
