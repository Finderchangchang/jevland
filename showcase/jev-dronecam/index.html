    jev drone cam

    作者 Todd Dailey 2026-10-15 开源项目 开源看图Box演示
    看图判断游戏与机器人决策

    Jev 在里面判断什么

    每帧并行一道 Box 框选目标和一道 Noul 判断目标是否在画面里

    它是什么

    jev drone cam 是一个可打开的网页演示：你给一张目标照片（杯子、植物、猫、书，也可以自己上传），模拟无人机在房间俯视图上逐格扫描。看见目标就飞到框的中心，看不见就扫下一格。作者 Todd Dailey 说想法来自 TypeSafe 员工 Nathan LeClaire 的 Box 演示视频，这个仓库把它做成了能跑的应用。

    仓库 2026-10-15 创建，同日发了带视频的帖子。模型默认 jev-1.14.0，图片输入要开 Danger Zone 头。

    Jev 在里面做什么判断

    每一帧把无人机画面和目标照片一起发给 Jev，同一请求里两道题：where 是 Box（框选题），问目标在无人机画面的哪里；seen 是 Noul（是非题），问目标是否出现在画面里。README 写明 Box 在目标不在画面里时仍会返回框，所以用 seen > 0.50 当门，不拿 Box 的置信度当「在不在」。一次调用大约 0.1 到 0.3 秒。
