    Box 框选实测

    作者 VerySmallWoods 2026-10-17 实验文章 实验看图Box
    看图判断

    Jev 在里面判断什么

    用 Box 标出图中目标位置，并观察目标不存在时仍会返回坐标

    它是什么

    VerySmallWoods 在 2026-10-17 发了一条约 11 分钟的实测视频：走 TypeSafe 官方接口，同一张自然照片连打三次 Box，再加一张圆、方、三角的控制图。对象包括清楚的目标、小目标、含糊目标，以及图里根本没有的东西。作者把返回坐标画回原图，用来看识别效果。

    这是实验记录，不是产品。没有找到单独的文章页或仓库。

    Jev 在里面做什么判断

    题型是 Box（框选题）。帖文记录：笔记本和多肉三次位置接近；台灯框能盖住但置信度明显低于笔记本；窗把手三次都落在相近区域；图里没有的自行车和紫色星星，Box 仍然返回四条坐标。作者写 Box 回答的是「目标在哪里」，不会用「没找到」当答案，接入时要另做是否存在的判断。
