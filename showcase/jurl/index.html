    jurl

    作者 Ray García 2026-10-05 开源项目 开源CLI抓取搜索

    Jev 在里面判断什么

    对页面块、链接和图片做是非相关性判断，过阈值的原文输出

    它是什么

    jurl 是一个命令行网页读取器：你问要什么，它只挑页面上已有的句子、代码、链接或图片，不改写。官网是 jurl.dev，源码 MIT 或 Apache-2.0。

    Show HN 日期 2026-10-05。首次运行会要 TypeSafe 控制台的 API 密钥。--vision / --find 看像素时另用 Cloudflare Workers AI。

    Jev 在里面做什么判断

    每个段落、链接或图片问「有多像你要的东西」，一次请求打许多块。站点示例是「is block 12 the point? p = 0.97」这种是非概率，对应 Noul。过阈值的内容按页面对顺序原样打印。

    怎么试

    官网可免密钥试用：jurl.dev/#try。安装：brew install rayoplateado/tap/jurl。仓库：rayoplateado/jurl。
