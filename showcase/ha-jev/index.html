    HA-Jev

    作者 AboveColin 2026-09-17 开源项目 开源Home Assistant智能家居
    其他

    Jev 在里面判断什么

    按配置用 Noul、Choice 或 Score 判断房屋状态，结果写成实体

    它是什么

    HA-Jev 把 TypeSafe Jev 接到 Home Assistant。每道类型化问题变成一个实体，可以拿来做自动化；文档站在 jev.cdevries.dev。

    仓库 2026-09-17 创建。作者声明与 TypeSafe 无隶属关系。HTTP 客户端是同作者的 jevclient。

    Jev 在里面做什么判断

    你配置关于家庭状态的问题。集成通过 jevclient 发 System One 请求，用 Noul、Choice 或 Score 更新实体。文档还提到四个自动化动作和 Assist 对话代理。

    怎么试

    文档：jev.cdevries.dev。仓库：AboveColin/HA-Jev。经 HACS 自定义集成安装，需要 TypeSafe API 密钥。
