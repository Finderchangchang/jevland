    实战示例

    Jev 实战示例合集：从几个问题到完整流水线，覆盖分类、抽取、护栏、重排序和记忆。按真实问题演示 TypeSafe 怎么接到代码里。

    非官方中文翻译 · 内容以 英文原文 ↗ 为准 · 同步于 2026-10-15

    每篇实战示例都包含一份真实数据集、针对它的 TypeSafe 决策问题，以及把这些决策转化为可运行系统的代码。当你想要了解 primitives 和 patterns 如何在一个具体问题上协同工作时，就阅读其中一篇；或者直接复制一篇，作为你自己的起点。

    本节假设你已经了解 TypeSafe primitives，并理解 confidence 如何运作。如果还没有，请先阅读这两部分。

    每篇实战示例都按其所解决的问题归类，且只列一次；其中很多还用到了其他章节的技巧。

    LLM 与智能体

    把 Jev 与大语言模型（LLM）或智能体配合使用：挑选工具与技能，对进出内容进行筛查，并核对返回结果。

    实战示例 功能 档位
    函数调用 通过把函数名和封闭集合参数映射到 confidence 感知的 TypeSafe 问题，把自然语言的交易请求转换为对普通类型化函数的调用。 中级
    技能推荐 在 Nous Research 的 Hermes 目录的 182 个技能中，为 agent 的一次 turn 选出至多一个，并通过两次 TypeSafe 请求对排名靠前的候选进行排序与复核。 中级
    LLM 安全护栏 用一次 TypeSafe 请求对进出 LLM 应用的每条消息进行筛查；将危害的 probability 与 severity 与阈值比对，决定是放行、人工复核、屏蔽还是路由。 中级
    双重核对引用 把引用与源文档进行比对，捕获错误或被幻觉出来的引用。一道 Choice（选择题）问题决定引文的上下文是否支持该论点。 初级
    对 RAG 段落分类 用一次 TypeSafe 请求对每条检索到的段落打分，再在代码中决定其中哪几条可以送到答题模型。 中级
    简易记忆系统 让 Jev 决定哪些请求和答案值得被记住，并把 Jev 的调用包成一个小函数，在后续调用中自动追加记忆。 初级

    分类

    把输入按任意深度分配到类别中。

    实战示例 功能 档位
    层次化分类 在专利、零售商品、生物医学和源代码的深层分类树中，通过基于 TypeSafe Choice probability 的并行束搜索对文档进行分类。 中级
    按 confidence 分类 用一个 Choice 把 SEC 年报分到 75 个 industry group 中，再读取 answer 自带的 confidence，决定是报出该 industry group 还是其上方更宽泛的 division。 初级
    Twitch 聊天过滤器 在 Twitch 聊天中隐藏侮辱、垃圾信息和未被询问的游戏攻略，把剧透涂掉，并把提问高亮。每条消息各对应一次包含多题的 TypeSafe 请求，最多 8 条消息并发处理，过滤规则由代码定义。 初级

    抽取

    从杂乱文本中抽出有类型的值与结构。

    实战示例 功能 档位
    SDE 级联 使用两阶段结构化数据抽取级联（mini → verify → reasoning），以极低的成本获得接近大型推理模型的质量。 中级
    日期抽取 先让 TypeSafe 给出文档中提到的各个日期组成部分，再在代码中基于 confidence 进行归一化与校验，由此抽取绝对日期和相对日期。 初级
    预解析值抽取 先用正则找出候选的邮箱、电话号码和金额，再让 TypeSafe 选出所请求的 span，由代码把该 span 归一化成精确值。 初级
    结构恢复 通过两次请求，从格式已经丢失的纯文本恢复 Markdown：一次把硬换行的行重新拼回段内，一次对每个 block（标题、列表、代码、callout）进行分类。 初级

    搜索与匹配

    查找匹配查询的行、段落或记录，以及彼此匹配的多条记录。

    实战示例 功能 档位
    重排序 为 40 条 CLERC 法律查询各构造一份 30 段 BM25 短名单，再用一道 TypeSafe 问题对每个查询-候选项对打分，把 top-1 准确率从 5% 提升到 18%，top-10 从 38% 提升到 62%。 中级
    按行搜索 为 GitHub 服务条款构建语义搜索：一次请求中用一道 Choice 问题为 218 个 line id 针对自然语言查询打分，并用一道 Noul（是非题）问题判断文档中是否包含答案。 初级
    知识图谱实体对齐 从两份啤酒目录的 450 对候选项中，判定哪一对描述的是同一款产品：用一道 Score（打分题）问题加三道配套 Noul，标出哪些字段不一致。 初级

    技巧

    让任何一道题发挥更大作用：重复它、批处理它，或把它的 answer 转成特征。

    实战示例 功能 档位
    自洽性：choices 在内容审核决策中纳入不确定的结果，并把标签一致性与自动处置所占的比例进行对比。 初级
    自洽性：nouls 把不确定的 probability 路由到人工复核，同时让底层的 Noul 值保持可见。 初级
    并行问题 针对 GDPR 维基百科词条给出一份包含 13 道题的监管简报；结果显示，把所有题打包到一次 TypeSafe 调用中，成本便宜 12.2 倍、速度快 10.0 倍，且 answer 完全不变。 初级
    Autoresearch 特征发现 运行一个 autoresearch 循环：提出 TypeSafe 问题，把自由文本转为数值特征，并借助模型错误来改进一个受监督的 CatBoost 回归器。 高级
