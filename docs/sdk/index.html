    客户端 SDK

    安装 TypeSafe 客户端 SDK，在应用里用带类型的方式向 Jev 提问并接收结构化答案，减少手写 HTTP 和解析样板。

    非官方中文翻译 · 内容以 英文原文 ↗ 为准 · 同步于 2026-10-15

    我们的客户端 SDK 为 TypeSafe API 提供带类型的问答，并按默认重试策略自动处理重试。

    选择一款客户端 SDK，查看安装说明、示例和 API 详情。

    • Python：安装 Python 客户端 SDK 并发起第一个请求。
    • JavaScript / TypeScript：安装 JavaScript 客户端 SDK 并发起第一个带类型的请求。

    您也可以使用任何语言直接调用 HTTP API。
