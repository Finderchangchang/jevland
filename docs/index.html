    入门

    简介

    Jev 是 TypeSafe 的旗舰判断模型，也是首个 System One 模型。传入 state 和类型化问题，直接返回代码可用的结构化答案，不生成文字。

    快速开始

    用 Jev 跑通第一个判断请求：申请 API key，选 SDK、HTTP API、agent skill 或 Playground 四条路之一，五分钟内看到带概率和置信度的答案。

    Jev 与编程智能体

    在编程智能体里，Jev 负责结构化判断而不是写代码。本页说明 Jev 适合做什么、不适合做什么，以及怎样接到 agent 工作流。

    用例地图

    按行业看 Jev 能接进哪些软件工作流：客服分流、审核、检索重排、抽取与对齐。把有潜力的判断想法落到可执行的代码路径里。

    核心概念

    System One

    System One 是为软件做快速、结构化判断的模型系列。Jev 是 TypeSafe 的旗舰 System One 模型，给 state 出题，返回带类型的答案。

    State（上下文状态）

    Jev 的 state 是判断所依据的上下文：字符串、对象或图片。本页说明如何组织 state，以及怎样给 System One 提供足够信息。

    怎样用 TypeSafe 构建

    怎样用 Jev 构建 AI 软件：让代码掌握控制权，把窄而结构化的判断交给 System One，避免把生成式模型硬拧成决策引擎。

    AI 入门

    介绍 TypeSafe 为何训练 Jev 这类决策模型时使用校准过的概率，而不是针对生成文本做优化，方便代码直接消费判断结果。

    置信度

    Jev 的置信度衡量这次判断能不能直接行动，和选项概率不是一回事。本页说明 TypeSafe 如何报告确定性，以及代码该怎么用它分流。

    题型

    题型总览

    Jev 四种题型总览：Choice 选择题、Score 打分题、Noul 是非题、Box 框选题。说明返回值形态、如何选题，以及一次请求提多个问题。

    Choice（选择题）

    Jev 的 Choice 选择题从固定选项里选出一个，返回所选选项、每个选项的概率和置信度，适合意图分类、动作选择等路由场景。

    Score（打分题）

    Jev 的 Score 打分题按你给的有序档位评分，返回加权分数、各档概率和置信度，适合风险、紧急程度、质量这类量表判断。

    Noul（是非题）

    Jev 的 Noul 是非题判断一个命题是否成立，返回答案为「是」的概率。适合催促、投诉、是否需要人工这类二元门槛判断。

    Box（框选题）

    Jev 的 Box 框选题在图片里标出目标位置，答案是相对宽高的矩形四边。适合截图里找按钮、头像、消息气泡等视觉定位任务。

    进阶：结构化写法

    Jev 题目的进阶结构化写法：instructions、Choice 选项、Score 档位和 Noul 的 criteria 都可以是 JSON，方便代码生成题目。

    图片

    在 Jev 请求里发送图片：放到 state、写进问题 instructions，或当作判定 criteria。本页说明看图请求怎么组、注意哪些限制。

    设计模式

    设计模式

    用 Jev 构建系统的架构设计模式：意图路由、置信度分流、组合打分、扇出与护栏。把题型组合成可维护的判断流水线，而不是堆提示词。

    推测式扇出

    Jev 的推测式扇出：一次调用发出多个问题，包括暂时不一定相关的题，再由代码根据答案决定哪些真正用得上，避免来回补问浪费。

    置信度分流

    把 Jev 置信度当作第二条判断轴：答案告诉你是什么，置信度告诉你能不能自动执行。高置信走代码，低置信交给人或大模型复核。

    组合打分

    把复杂判断拆成若干 Jev 子项打分，再用代码里指定的权重合成总分。适合多因素风险、质量评估和需要可解释权重的场景接入。

    意图路由

    用 Jev 对传入请求做分类，再路由到确定性逻辑、专业大语言模型或人工。意图路由是把判断模型和代码控制权接起来的常用模式。

    客户端 SDK

    安装 TypeSafe 客户端 SDK，在应用里用带类型的方式向 Jev 提问并接收结构化答案，减少手写 HTTP 和解析样板。

    Python SDK

    安装 TypeSafe Python SDK，用同步或异步方式调用 Jev API，把 state 和 questions 写成普通函数参数。

    实战示例

    实战示例

    Jev 实战示例合集：从几个问题到完整流水线，覆盖分类、抽取、护栏、重排序和记忆。按真实问题演示 TypeSafe 怎么接到代码里。

    函数调用

    把自然语言交易请求映射成带置信度的 Jev 问题，函数名和闭合取值集合由代码执行，相当于用判断模型做受控的函数调用网关。

    技能建议

    每个智能体回合用两次 Jev 请求，从技能目录里至多选出一个技能：先排序再复检，把技能建议做成带置信度的结构化判断步骤。

    大语言模型的安全护栏

    用一次 Jev 请求筛查进出大语言模型的消息，按风险概率和严重程度设阈值，决定放行、复核、拦截还是改路由给人工处理坐席。

    二次核对引用

    用 Jev 的 Choice 题把声明和源文档比对，找出错误或虚构的引用：判断引文上下文是否支撑该声明，再交给代码处理。

    为 RAG 段落分类

    用一次 Jev 请求给每条检索段落打分，再用代码决定哪些段落进入生成答案的模型，把判断从 RAG 生成流程里彻底拆出来。

    简单记忆系统

    让 Jev 决定哪些请求和答案值得记住，再把调用包进小函数，在后续判断里带上这些记忆，做成最简单可用的会话记忆系统示例。

    层次分类

    用 Jev Choice 概率做并行束搜索，在专利、商品、生物医学和源代码等深层次结构上给文档做层次分类，而不是一次猜到底。

    使用置信度进行分类

    用一道 Jev Choice 把 SEC 年报分进 75 个行业组，再按置信度决定是报该组，还是上收到更宽的行业门类，避免硬切。

    Twitch 聊天过滤器

    用 Jev 过滤 Twitch 聊天：隐藏侮辱和垃圾信息、模糊剧透、高亮提问。每条消息一次多问题请求，规则全由代码定义。

    SDE（结构化数据抽取）级联

    用两阶段结构化数据抽取级联（mini 到 verify 再到 reasoning）接 Jev，小成本逼近大型推理模型的抽取质量。

    日期提取

    用 Jev 从文档里提取绝对日期和相对日期：模型先读被点名的日期片段，代码再解析校验，并按置信度决定要不要交给人工复核。

    预先解析的值抽取

    先用正则找出邮箱、电话和金额候选，再让 Jev 选出题目要的那段文本，由代码规范化原样值，避免模型凭空编造数字或格式串。

    结构恢复

    用两次 Jev 请求从丢失格式的纯文本重建 Markdown：一次把硬换行拼回段落，一次给每个块分类成标题、列表、代码或提示框。

    重排序

    用 Jev 给 BM25 短列表重排序：法律查询实验里 top-1 和 top-10 准确率都明显提升，展示判断模型做重排的接法。

    逐行搜索

    用 Jev 做逐行语义搜索：一次请求里 Choice 给行 ID 打分，Noul 检查文档是否包含答案，示例基于 GitHub 服务条款。

    知识图谱实体对齐

    用一个 Jev Score 加三道 Noul，从两份啤酒目录的候选配对里判断是否同一产品，并标出名称、酒精度等哪些字段存在分歧。

    自一致性：Choice

    为内容审核的 Jev Choice 引入不确定结果，比较标签一致性和自动处理占比，看自一致性如何影响可自动放行的业务比例。

    自一致性：Noul

    把 Jev Noul 的不确定概率分去人工复核，同时保留底层 noul 值可见，用来在自动处理和人工之间找可运营的平衡。

    并行提问

    一次 Jev 调用批量提出多个问题：以 Wikipedia GDPR 词条的 13 问合规简报为例，比逐条调用更便宜也更快，答案一致。

    自动研究：特征发现

    跑一个 autoresearch 循环，让 Jev 提出问题，把自由文本转成数值特征，并用模型误差改进有监督的 CatBoost 回归器。
