    用例地图

    按行业探索 TypeSafe 的用例，把有潜力的想法转化为软件工作流。

    非官方中文翻译 · 内容以 英文原文 ↗ 为准 · 同步于 2026-10-15

    借助这张图，在你的行业中头脑风暴 TypeSafe 可能适合的位置。打开与你最贴近的行业，浏览示例决策，再把它们适配到你自己工作流中的文档和操作上。

    示例用例分类

    • AI 自动化软件：在后台无需人类介入地运行数百万次，把 AI 与可靠软件交织在一起。控制流由代码掌控（而不是 Markdown 文件），由 TypeSafe 负责语义决策和语言理解。
    • 实时应用：以实时速度（150ms）提供前沿级别的智能水平，意味着 AI 可以比人类感知更快地做出决策。足够快、足够聪明，可以被编程用来玩游戏，或嵌入到 UI 中。
    • 面向大数据的 AI Map Reduce：便宜 100 倍意味着你可以处理海量数据集。在庞大的语料中搜索相关信息，对大规模智能体 trace 做分类，并抽取特征用于预测。
    • 通用验证：验证任何其他 AI 的输入提示、抽取内容、推理 trace、工具调用或输入。以远低于实际大语言模型（LLM）调用成本的开销，检测越狱、引用错误、幻觉、失误，以及其他 AI 或 LLM 容易犯的错误模式。
    • Harness 工程：借助 Jev 查询让你的 harness 更智能——模型路由、语义上下文检索、LLM 错误检测与安全护栏，以及以极快的速度和低很多的成本进行推理 trace 分类。

    示例自动化用例

    搜索与检索

    • 在 RAG 流水线中，以语义搜索、打分和排序替代或补充嵌入。
    • 对查询与候选项之间的相关性打分。
    • 用两两比较对结果重排序。
    • 对查询和候选项做交叉编码以获取更高精度。
    • 为下游 AI 工作流挑选有用的上下文。

    科学研究

    • 根据纳入和排除标准对论文做筛选，用于系统性综述。
    • 用预定义的主题或类别，给访谈记录、开放式问卷回答和田野笔记中的段落打标签。
    • 检查被引用的段落是否支撑稿件和生成式摘要中的论断。
    • 标记缺失的方法细节，比如对照设置、数据集描述和实验配置。
    • 跨论文识别实体和关系，构建研究知识图谱，把研究发现与其支撑段落关联起来。

    模型路由

    • 使用 Jev 构建自定义路由器，决定每条提示分配给哪个 LLM。
    • 为你的特定工作流设置路由规则和阈值。
    • 对意图和领域做分类。
    • 估计难度和风险。
    • 升级那些需要更昂贵模型的请求。

    LLM 安全护栏

    • 在每次 LLM 输入、输出和工具调用上加语义检查，成本远低于 LLM 调用本身。
    • 检测越狱和提示注入。
    • 识别违反策略和敏感数据泄露。
    • 实时检测工具调用错误和响应质量问题。
    • 记录结构化的检查结果和概率，让 AI 系统和 harness 失败更易于追溯。

    语义代码检查

    • 使用 Jev 查询为代码和写作加上自动化的语义 lint。
    • 为你团队的编码规范和写作指南定义检查。
    • 在 CI 中运行这些检查，并标记违规以供审查。

    用于预测建模的特征抽取

    • 使用 Jev 从自然语言数据中抽取概率性特征。
    • 把这些特征与结构化数据结合，训练具有真实结果的预测任务模型。
    • 用 autoresearch 工作流提出特征定义，并在保留的真实数据上评估它们的预测价值。

    招聘

    • 用明确且与岗位相关的判定标准（criteria）评估简历、应聘材料和面试反馈。
    • 识别相关经验。
    • 为必需的胜任力项提供打分依据。
    • 把候选人匹配到岗位。
    • 把候选人路由到用人经理或招聘人员。
    • 升级不确定的候选人到人工复核。

    线索生成

    • 把公司简介、高管传记和入站消息匹配到理想客户画像。
    • 给行业适配度和公司成熟度打分。
    • 检测买家相关性、痛点和购买意图。
    • 对线索排序并路由。

    客户支持

    • 按问题、产品领域和客户意图对进来的工单分类。
    • 处理通话记录，提取客户问题、承诺和后续动作。
    • 检测紧迫度、挫败感、流失风险和退款请求。
    • 把工单路由到合适的团队、队列或自动化工作流。
    • 核验支持回复是否符合策略和客户请求。

    保险理赔

    • 对首次出险报告、理赔员备注和支撑文件分类。
    • 检测理赔的复杂度、缺失信息和潜在欺诈信号。
    • 对可以直通处理的理赔或专家复核进行优先级排序。
    • 升级不确定或高风险案件到人工理赔员。

    金融犯罪

    • 针对交易说明、KYC 文档和告警历史评估可疑特征。
    • 在名称、简介和记录不一致的实体之间做匹配。
    • 按风险、相关性和证据质量对告警排序。
    • 把模糊的案件路由给调查员复核。

    法律与合规

    • 对合同、政策、监管申报和市场声明分类。
    • 检测缺失的条款、禁止的声明和违反策略的情况。
    • 按明确的法律或合规要求核验文档。
    • 把高风险或不确定的发现升级给法务或合规团队。

    电商市场

    • 跨不一致的卖家目录对商品列表做分类和归一化。
    • 从标题和描述中抽取商品属性。
    • 检测禁止商品、假冒信号、评价作弊和违反策略的情况。
    • 给商品排序，把不确定的商品列表路由到人工复核。

    内容审核与信任安全

    • 用公司特有的、细致的判定标准（criteria）决定哪些帖子符合你的审核标准。
    • 跨社区、客服和 SDR 工作流审核用户内容和自动化对话。
    • 检测毒性、骚扰、垃圾信息、欺诈、不安全建议、个人数据泄露、退出请求和违反策略的声明。
    • 结合严重度和置信度，决定放行、警告、复核或屏蔽内容。

    广告

    • 评估创意素材、广告活动文案、落地页和投放上下文。
    • 对品牌安全和受众适配性分类。
    • 检查监管合规和禁止声明。
    • 评估创意质量以及广告与落地页的一致性。

    游戏

    • 评估玩家举报、游戏内聊天、评价和支持会话。
    • 审核聊天并检测滥用、毒性或可疑行为。
    • 标注内容并打分挫败度或参与度。
    • 检测流失信号并路由玩家支持请求。

    风险评估

    • 把事件报告、理赔备注、交易描述和供应商评估转化为概率性的风险指标。
    • 把这些指标用于保险和承保工作流。
    • 对风险类型分类并检测可疑特征。
    • 给严重度打分并安排复核优先级。
    • 为更广泛的风险模型抽取特征。

    需求预测

    • 用客户咨询、销售备注、商品评价、支持工单和市场报告中的语义信号丰富预测模型。
    • 抽取购买意图、紧迫度和商品兴趣。
    • 检测供应隐患、竞争压力和新兴需求主题。
    • 把这些特征连同历史时序数据一起喂给预测模型。

    图与知识图谱

    • 用类型化的语义决策来标注和核验知识图谱。
    • 对关系和实体类型分类。
    • 检测记录或声明之间的矛盾。
    • 支持概率性的图遍历和分层分类。

    示例任务类别

    决策形态 适用场景 示例
    分类（Classification） 需要从已知类别中选出唯一胜出者 意图、主题、部门、风险类型、实体类型
    检测（Detection） 需要判断某个属性是否存在的概率 垃圾信息、欺诈、紧急程度、越狱攻击、敏感数据
    打分（Scoring） 答案落在某个有序量表上 严重程度、相关性、质量、挫败感、契合度
    路由（Routing） 由类别决定下一段代码路径 工具调用、升级处理、模型路由、工单队列
    搜索（Search） 需要根据自然语言查询找到匹配的条目 语义搜索、文档发现、候选生成
    检索（Retrieval） 工作流需要最相关的上下文或记录 RAG 上下文、证据检索、知识查询
    排序（Ranking） 需要按语义相关性或质量对条目排序 搜索结果、推荐、候选优先级
    验证（Verification） 需要对产物检查是否存在特定的失败模式 引用支撑、违规情况、工具调用错误、响应质量
    机器学习特征提取（ML Feature Extraction） 下游传统机器学习模型需要语义信号 购买意向、产品兴趣、竞争压力、流失信号
    结构化数据提取（Structured Data Extraction） 需要从非结构化输入中恢复已知字段 候选属性、订单字段、文档标签
